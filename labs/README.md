# Practice Labs

This directory contains hands-on exercises and practice scenarios for the CKA exam.

## Lab Categories

### 1. Basic Operations
- Pod creation and management
- Service exposure
- ConfigMap and Secret usage

### 2. Scheduling
- Manual pod scheduling
- Node affinity exercises
- Taint and toleration scenarios

### 3. Networking
- Service types (ClusterIP, NodePort, LoadBalancer)
- Ingress configuration
- Network policy implementation

### 4. Storage
- Volume mounting
- Persistent Volume claims
- Storage class usage

### 5. Troubleshooting
- Pod failure scenarios
- Network connectivity issues
- Resource constraint problems

### 6. Security
- RBAC configuration
- Security context implementation
- Network policy enforcement

### 7. Maintenance
- Node drain and cordon
- Cluster backup and restore
- Version upgrades

## Lab Format

Each lab includes:
- **Objective**: What you'll learn
- **Prerequisites**: Required knowledge
- **Steps**: Detailed instructions
- **Verification**: How to check your work
- **Cleanup**: Resource cleanup commands

## Getting Started

1. Start with basic operations
2. Progress through each category
3. Time yourself on exam-style questions
4. Practice troubleshooting without looking at solutions first

## Exam Simulation

- Set a 2-hour timer
- Complete 15-20 questions
- Use only kubernetes.io documentation
- Practice kubectl efficiency
